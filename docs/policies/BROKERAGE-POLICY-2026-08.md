## 2. 법령 구조와 지역 처리

### 2.1 시·도 조례 위임

**공인중개사법 제32조 제4항**: 주택 중개보수의 한도 등은 **국토교통부령이 정하는 범위 안에서**
특별시·광역시·도 **조례**로 정한다. **주택 외**는 국토교통부령이 직접 정한다.

시행규칙 별표의 정식 명칭이 **「[별표 1] 주택 중개보수 상한요율(제20조제1항 관련)」** 로,
명칭에 "상한요율"이 박혀 있어 조례가 넘을 수 없는 천장이라는 점이 조문 레벨에서 확인됩니다.

서울시 공식 페이지가 항목별 근거를 다르게 표시하는 것이 이 구조의 실증입니다 —
주택 매매/임대차는 **조례 제2조 별표1**, 오피스텔·주택 외는 **시행규칙 제20조 제4항**.

### 2.2 확인된 지역

| 시·도 | 상태 | 확인처 |
|---|---|---|
| **서울특별시** | ✅ 국토부 상한과 **일치** | 서울시 부동산정보광장, 국가법령정보센터 조례 원문 |
| **경기도** | ✅ 국토부 상한과 **일치** | 경기부동산포털 |
| 나머지 15개 시·도 | ❌ **미확인** | — |

### 2.3 v1 설계 — 시·도 폴백 구조는 만들지 않습니다

rev.1 은 `Record<SidoCode, BrokerageTable>` 에 서울 표를 기본값으로 두는 구조를 제안했습니다.
**폐기합니다.**

미확인 지역에 서울 표를 조용히 반환하면, 계산기가 **확인하지 않은 지역 조례를 확정값처럼**
보여주게 됩니다. LTV 문서 8절에서 세운 원칙("공식 근거 미확인 → 값을 만들지 않는다")과
정면으로 어긋납니다. 폴백은 `unsupported` 를 값으로 위장하는 방식입니다.

**v1 구조**

```
basis:  "nationalCeiling"          // 국토교통부 상한 단일 정책
label:  "국토교통부 상한 기준 예상 최대 중개보수"
verifiedLocalOrdinances: ["서울특별시", "경기도"]
```

- 시·도 입력을 **받지 않습니다.** 국토부 상한 하나로 계산합니다.
- 결과 라벨과 안내에 다음을 명시합니다.
  - 서울·경기는 조례가 국토부 상한과 **일치함이 확인**되었습니다.
  - 그 외 지역은 **해당 시·도 조례를 확인해야 하며, 이 결과는 국토부 상한 기준 참고값**입니다.
- **"지역별 법정 최대"라고 표현하지 않습니다.** 확인된 것은 상한이지 각 지역의 조례값이 아닙니다.

시·도별 차이가 실제로 확인되는 날 `basis` 를 `localOrdinance` 로 확장하면 됩니다.
그때까지는 구조를 미리 만들어 두지 않습니다 — 빈 구조가 있으면 채우고 싶어집니다.

## 3. 실무 규칙

### 3.1 상한 vs 정가 — **상한입니다**

> "중개보수는 거래금액 × 상한요율 **이내에서 협의**하여 결정(한도액 초과 불가)" — 서울시(준1차)

계산기 라벨은 **"예상 최대 중개보수"** 입니다. "중개보수"라고만 쓰면 정가처럼 읽힙니다.

### 3.2 부가가치세 — 별도, 일반과세 10% 기본 포함

- 서울시(준1차): "부가가치세 **별도** 부과" — 요율표 금액은 VAT 제외
- 일반과세자: 10% 별도 청구
- **간이과세자**: 실무가 갈린다는 2차 서술만 있고 구체 요율 **확인 불가**

**v1 처리 (E2 확정)**

| 항목 | 값 |
|---|---|
| 기본값 | 부가세 10% **포함** |
| 토글 | 제외 가능 |
| 결과 라벨 | **"일반과세 중개사 기준 예상 최대"** |
| 안내 | "간이과세 중개사는 다를 수 있으니 확인 필요" |

방공제와 처리가 반대인 이유: 방공제는 **적용하지 않으면 과대 표시**라 명시 선택을 요구했고,
부가세는 **적용하지 않으면 과소 표시**입니다. 15억 매매 기준 약 105만원 차이입니다.
확인된 원칙(별도 + 일반과세 10%)이 있으므로 기본값으로 적용하되, 라벨에 전제를 박습니다.

### 3.3 거래금액 산정

| 거래 | 거래금액 |
|---|---|
| **매매** | 매매가격 (별도 규칙 없음). 주택분양권 포함 |
| 전세 | 보증금 |
| 월세 | 보증금 + (월차임 × 100). 이 값이 5천만원 미만이면 보증금 + (월차임 × 70) |
| 복합용도 건축물 | 주택 면적이 **1/2 이상**이면 주택 요율 |

지급시기: 약정이 없으면 거래대금 지급 완료일. **v1은 매매만 지원**합니다.

## 7. `publishedAt` 기재 규칙

PR 1 에서 `2026년도 가계부채 관리방안` 의 `publishedAt` 에 **기사 작성일(2026-04-09)** 을
넣은 오류가 있었습니다. 조사 문서에서는 발표일을 "확인 불가"로 남겨두고 코드에는 확정값처럼
기재한 것이 문제였습니다.

> **최종 상태**: `2026-04-09` 는 기사 작성일이므로 폐기. **`2026-04-01`** 은 금융위원회 원문
> (회의 일시·게시일)에서 확인된 발표일이므로 **유지**합니다. 현재 코드 값은 근거가 있습니다.

**규칙** — 조사 문서와 `PolicySource.publishedAt` 주석 양쪽에 둡니다.

