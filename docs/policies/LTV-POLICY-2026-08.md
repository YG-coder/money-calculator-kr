## 2. 조건별 LTV 표 (2026-08-25 기준)

```
차주 구분 = 무주택(처분조건부 1주택 포함) / 유주택 / 생애최초
지역 구분 = 규제지역 / 수도권 비규제 / 비수도권 비규제
```

| 차주 구분 | 규제지역 | 수도권 비규제 | 비수도권 비규제 | 근거 |
|---|:--:|:--:|:--:|---|
| 무주택 (처분조건부 1주택 포함) | **40%** | **70%** | **70%** | S1 각주, S9 |
| 생애최초 | **70%** | **70%** | **80%** | S8, S9 |
| 유주택 (1주택 비처분·다주택) | **0%** | **0%** | **60%** | S1 각주, **S2** |
| 주택가격 구간별 절대한도 | **적용** | **적용** | **미적용** | S1 본문 |
| 생활안정자금 주담대 1억 한도 | 적용 | 적용 | 미적용 | S1 |

### 2.1 유주택자 0% 적용 범위 — 수도권 전역

금융위 「2025년 가계부채 관리 강화 방안」(S2)이 **수도권**에서 다음을 `LTV 0%`로 명시합니다.

- 2주택 이상 보유자의 추가 구입
- 기존 주택을 처분하지 않는 1주택자의 추가 구입
- **처분조건부 1주택자는 무주택자와 동일 적용**

즉 규제지역만이 아니라 **수도권 비규제지역에도 유주택자 0%가 적용**됩니다.
10·15 대책 각주가 `非規制地域(수도권 外)` 로 한정한 것은 이 때문이며, 60%는 **비수도권**
비규제지역에만 해당합니다.

### 2.2 10·15 대책 원문(S1) 각주

```
주택구입목적 주담대
 - LTV : 무주택(처분조건부 1주택 포함) 40%, 유주택 0%
 * 非規制地域(수도권 外) 무주택(처분조건부 1주택) 70% / 유주택 60%
```

## 4. 담보 기준 한도 산식

### 4.1 LTV의 규정상 정의 — 차감항목이 분자에 들어갑니다

독립된 준1차 자료 2건이 동일한 산식을 씁니다.

**한국주택금융공사 업무처리기준(S10) 제6장 2. LTV 산출방법**
```
LTV = (본건 대출금액 + 선순위채권 + 임대보증금 및 최우선변제 소액임차보증금) × 100
      ────────────────────────────────────────────────────────────────────
                              담보주택 평가액
```

**신한은행 상품설명서(S11)**
```
(주택담보대출금액 + 선순위채권 + 임차보증금 및 최우선변제 소액임차보증금) / 담보가치 × 100
```

대출금액에 대해 정리하면:

```
대출금액 ≤ 담보가치 × LTV − 선순위채권 − 임대차차감
```

**즉 차감은 LTV 적용 후 대출금액 쪽에서 일어납니다.**

### 4.2 절대한도의 적용 위치 — 차감 후

6·27 대책 원문 문구는 *“금융회사가 수도권 규제지역 내에서 취급하는 **주택구입목적 주담대의
최대한도를 6억원으로 제한**”* 입니다. 규제 대상 변수가 **실제 대출 실행액**이므로, 절대한도는
차감을 마친 값에 씌웁니다.

“차감 전 담보인정액에 절대한도를 씌운다”는 취지의 문구는 **어느 자료에서도 확인되지
않았습니다.**

### 4.3 확정 산식

```
임대차차감 =
  임대차 없음   → min(공제방수 × 지역별 최우선변제금, 평가액 × 0.5)
  전부 임대차   → 임대보증금 전액
  일부 임대차   → min(공제방수 × 지역별 최우선변제금, 평가액 × 0.5) + 임대보증금

담보기준한도 = max(0, min(
    담보가치 × 적용LTV − 선순위채권 − 임대보증금 − 최우선변제 소액임차보증금,
    절대한도(6억 / 4억 / 2억)      ← 수도권·규제지역만
))

실제한도 = min(담보기준한도, DSR 기준 한도)
```

> `임대차차감`의 `공제방수`는 **HF 기준 규칙**입니다(5.3절). v1은 이 항을 자동 산정하지 않고
> **사용자 입력 금액**으로 받습니다 — 일반 은행 내규 근거가 없기 때문입니다.

### 4.4 B가 도출되는 근거 — 두 공식 제약의 결합

산식 B는 해석이 아니라 **두 개의 공식 제약을 동시에 만족시키면 유일하게 나오는 결과**입니다.

**제약 ① — 은행업감독업무시행세칙 [별표 18] (S13, 1차)**

```
LTV = (담보대출금액 + 선순위채권 + 임차보증금 및 최우선변제 소액임차보증금) ÷ 담보가치
```

담보대출금액에 대해 정리하면:

```
담보대출금액 ≤ 담보가치 × LTV − 선순위채권 − 임차보증금 − 최우선변제 소액임차보증금
```

**제약 ② — 금융위원회 대출한도 규정 (S4, 1차-공개)**

금융위는 6억·4억·2억을 담보인정액이 아니라 **주택구입목적 주담대의 한도**로 규정합니다.

```
담보대출금액 ≤ 절대한도
```

**결합**

두 제약 모두 좌변이 **같은 변수(담보대출금액)** 입니다. 동시에 만족시키는 최대값은 두 상한의
최솟값이고, 차감 결과가 음수일 수 있으므로 0으로 클램프합니다.

```
담보기준한도 = max(0, min(
    담보가치 × LTV − 선순위채권 − 임대보증금 − 최우선변제 소액임차보증금,
    절대한도
))
```

**A안이 성립하지 않는 이유**: A안 `min(담보가치×LTV, 절대한도) − 차감` 은 절대한도를 차감 전
값에 씌웁니다. 그러면 제약 ②의 좌변이 담보대출금액이 아니라 담보인정액이 되는데, 금융위
문언은 절대한도의 대상을 “**금융회사가 취급하는 주담대의 최대한도**”, 즉 실행 대출액으로
규정합니다. A안은 제약 ②를 잘못 읽은 결과입니다.

> 별표 18에 `min()` 형태가 직접 쓰여 있지는 않습니다. 두 제약을 **연립**으로 풀면 B가
> 유일해지므로, 이는 추가 해석이 아니라 산술적 귀결입니다.

**rev.1 → rev.2 정정 내역** (회귀 케이스로 보존)

| 조건 | A안 (틀림) | B안 (맞음) |
|---|---|---|
| 수도권 20억, LTV 40%, 선순위 0, 방공제 5,500만 | `min(8억, 4억) − 0.55억` = **3.45억** | `min(8억 − 0.55억, 4억)` = **4억** |

**A와 B의 결과가 갈리는 조건**: `담보가치 × LTV > 절대한도` 이면서 차감액이 0보다 클 때.
즉 **수도권·규제지역에서 절대한도가 실제로 걸리는 구간**입니다. 그 밖의 구간에서는 두 안이
같은 값을 냅니다 — 그래서 테스트 케이스를 이 구간으로 잡지 않으면 회귀를 못 잡습니다.
(9.1절 참조)

### 5.3 공제방수 — HF 기준

**⚠️ 적용 범위 주의.** 아래 표는 **한국주택금융공사 정책모기지(디딤돌) 업무처리기준**의
규칙입니다. **일반 시중은행 자체 주담대에 동일하게 적용된다는 근거는 확보하지
못했습니다**(은행별 여신업무방법서 비공개). 머니계산기는 일반 은행 주담대 계산기를
표방하므로 이 표를 일반 규칙으로 제시하면 안 됩니다.

HF 업무처리기준(S10)의 공제방수 표입니다. 열 머리글이 **「전체 방수 중 임대차 없는 방수」**
입니다.

| 주택 유형 | 전체 방수 중 임대차 없는 방수 | **공제방수** |
|---|---|:--:|
| 아파트 | 1개 이상 | **1개** |
| 연립주택, 다세대주택 | 1개 이상 | **1개** |
| 단독주택 | n개 | **n개** |
| 저가 단독주택 (수도권 3억 / 수도권 외 2.5억 이하) | 3개 이하 | **1개** |
| | 4개 이상 | **2개** |

**핵심**: `총 방 수 − 임대 방 수`는 **표의 입력값**일 뿐이고, 그 값을 그대로 곱하지 않습니다.
주택 유형별 매핑을 한 번 더 거칩니다.

**HF 기준에서는** 아파트·연립·다세대의 공제방수가 1건이고, 단독주택은 임대차 없는 방 수
n개 전부이며, 저가 단독주택은 1~2개로 축소됩니다.
**일반 은행 주담대의 적용 방식은 금융회사 내규에 따라 달라질 수 있습니다.**

> rev.1의 “다가구는 임대 가능한 방 수만큼 공제”는 **부정확**했습니다.
> rev.2의 “아파트·연립·다세대는 무조건 1건”은 **HF 기준에 한정된 서술**이어야 했습니다.

**총액 상한**: `min(공제방수 × 최우선변제금, 평가액 × 50%)` (제10조 ②항과 정합).

#### v1 방공제 처리 방식 — 세 가지 선택지

HF 기준을 일반 은행 규칙으로 일반화할 수 없으므로, v1은 셋 중 하나를 골라야 합니다.

| 안 | 방식 | 장점 | 단점 |
|---|---|---|---|
| **① 직접 입력 (권장)** | 방공제액을 사용자가 입력. 지역별 법정 금액을 **참고표로 제공** | 은행 내규 차이에 영향받지 않음. 계산기가 확인되지 않은 규칙을 주장하지 않음 | 입력 1단계 증가 |
| ② 제한형 | 공동주택 1건 적용하되 “**HF 기준 간이 계산**”임을 명시 | 입력이 간편 | 일반 은행 주담대 계산기가 정책모기지 규칙을 쓰게 됨 |
| ③ 보수형 | 방공제를 v1에서 제외, v1.1로 이월 | 가장 안전 | 담보 기준 한도가 실제보다 크게 나옴 — 과대 표시 |

**권장: ①.** 머니계산기는 일반 은행 주담대 계산기를 표방합니다. 지역별 법정 금액
(서울 5,500만 등)은 확정된 사실이므로 **참고 정보로 제공**하고, 그것을 몇 건 적용할지는
사용자가 자기 조건으로 넣게 하는 것이 정확합니다. ③은 방공제를 아예 빼서 한도를 과대
표시하므로 8절 원칙(과대 표시 회피)에 어긋납니다.

**다가구주택**: HF 업무처리기준에 **단어 자체가 등장하지 않습니다.** 건축법상 단독주택
분류이므로 실무상 단독주택 행이 적용되는 것으로 보이나 **명문 확인 불가** → v1 제외.

**무상거주인**: 퇴거 조치 또는 무상거주확인서 징구 시 임대차 없는 것으로 간주.
미징구 시 대출 취급 불가. (미성년자, 채무자·배우자의 직계존비속은 확인서 생략)

### 5.4 기준 시점 — 근저당 설정일

**최선순위 담보물권(근저당권) 설정등기 접수일 당시 시행되던 시행령**을 적용합니다.

- 시행령 부칙 제2조(S16): *“이 영 시행 전에 임차주택에 대하여 담보물권을 취득한 자에
  대해서는 종전의 규정에 따른다”*
- 대법원 2001다84824(S17): *“위 법률 시행 후에 설정된 근저당권에 대하여는 위 법률의 규정에
  따라 소액임차인에 해당하는지 여부를 가리는 것이 원칙”*

**계산기 함의**: 신규 주담대는 지금 근저당을 새로 설정하므로 **항상 현행(2023-02-21) 금액**이
적용됩니다. **날짜 입력 불필요.** 과거 시행령 소급은 후순위·추가담보대출에만 필요 → v1 제외.

### 5.5 MCI / MCG

보증기관이 최우선변제금 상당액을 보증해 방공제 없이 LTV 한도까지 대출하는 구조입니다.

HF는 MCG를 **주담대에서 공제되는 최우선변제 소액임차보증금을 보증해 한도를 늘리는 상품**으로
설명하고, 보증한도를 **`지역별 소액임차보증금 × 적용방수`** 에 기초해 산정합니다(S18).
HF 업무처리기준(S10)도 *“LTV 산식에서 **MCG 적용 시 지역별 소액보증금을 공제하지 않고**
주택담보대출비율(LTV)까지 대출을 지원”* 이라고 씁니다 — 산식의 최우선변제금 항을 0으로
만드는 장치입니다.

| | MCI | MCG |
|---|---|---|
| 운영기관 | 서울보증보험(SGI) | 한국주택금융공사(HF) |
| 보험·보증료 부담 | 은행 | 차주 |

**v1 처리 — 정책값과 취급 상태를 분리합니다.**

| 항목 | 처리 |
|---|---|
| 계산 로직 | 가입 여부를 **사용자가 직접 선택** |
| 기본값 | **미가입** |
| 안내 문구 | “가입 가능 여부와 조건은 금융회사별로 다르므로 확인이 필요합니다” |
| 하지 않을 것 | “사실상 이용 불가”, “대부분 은행 중단” 같은 **시점 의존 단정** |

은행별 취급 중단·재개는 시점과 금융회사에 따라 달라지므로 정책 테이블에 넣지 않습니다.
넣으면 갱신 주기가 정책값보다 훨씬 짧아져 관리가 불가능해집니다.

### 5.6 DSR과의 관계

방공제를 반영한 담보 기준 한도와 **DSR 기준 한도 중 낮은 쪽**이 실제 한도입니다.
방공제가 면제되어도 그만큼 한도가 늘어난다는 보장이 없습니다.
→ 결과에 기존 `/dsr-calculator` 링크를 반드시 배치합니다.

| **공제방수 자동 산정** | HF 기준은 확보했으나 일반 은행 내규에 동일 적용된다는 근거 없음 → 금액 직접 입력으로 회피 |
| **임대차가 있는 경우** (일부·전부) | 임대보증금 합산 규칙은 HF 기준으로 확보했으나 일반화 근거 부족 + 입력 복잡도 |
| **DTI** | 투기과열 40% / 조정대상 50% 구분의 현행 유효성 미확인 |
| **서민·실수요자 우대** | 수치·요건 공식 근거 미확보 |
| **정책대출** (디딤돌·보금자리론·신생아 특례) | 별도 상품 체계 |
| **생활안정자금 목적 주담대 1억 한도** | v1은 주택 구입 목적만 |
| **후순위·추가담보대출** | 선순위 근저당 설정일 기준 과거 시행령 소급 필요 |
| **전세대출·전세퇴거자금·임대사업자·신탁대출** | 별도 규제 체계 |
| **비주택 담보** (오피스텔·상가·토지) | LTV 체계 자체가 다름 |
| **복합용도 건축물 상가 부분** | 별도 산식 (전체 사업장수 × 상가 최우선변제금 vs 상가 평가액 1/2) |
| **규제지역 자동 판정** | 고시 후 1~2일 만에 발효되어 목록이 낡음 |

### 6.3 `docs/CALCULATOR-EXPANSION.md` Q1에 대한 답

|---|---|

## 8. 출처 충돌 시 처리 원칙

### 8.1 원칙 (rev.2 — “낮은 값 채택” 폐기)

1. **등급이 높은 출처를 우선한다.** 1차 > 준1차 > 2차. 2차끼리 다수결로 정하지 않는다 —
   같은 오류가 복제되는 경우가 흔하다.
2. **공식 근거가 확인되면 값을 반환한다.**
3. **공식 근거가 확인되지 않으면 `unsupported` 를 반환하고 금융회사 확인을 안내한다.**

> **rev.1의 “확인 불가 시 낮은 값 채택”은 폐기했습니다.**
> 낮은 값을 보여주는 것도 **확인되지 않은 정책값을 제공하는 것**입니다. 사용자는 그 값이
> 보수적으로 만들어진 값인지 알 수 없고, 화면 고지를 읽지 않으면 그냥 “한도”로 받아들입니다.
> `lookupPolicy` 가 처음부터 `unsupported` 를 반환하도록 설계된 이유가 이것입니다.
> **모르면 값을 만들지 않고 모른다고 말합니다.**

4. 해소되지 않은 충돌은 이 문서에 양쪽을 그대로 남긴다.
5. 조건 조합 자체가 확인되지 않으면 값을 만들지 않는다.

### 8.2 이번 조사에서 실제로 적용한 사례

| 충돌 | 갈린 값 | 처리 |
|---|---|---|
| 절대한도 적용 범위 | 규제지역만 / 수도권 / 전국 | **1차(S1)로 해소** — “수도권·규제지역 내” |
| 비규제 생애최초 LTV | 70% / 80% | **해소** — 수도권·규제 70%, 그 외 80%. “생애최초 70%”는 지역 한정 생략 |
| 수도권 비규제 유주택 | 60% / 0% | **1차-공개(S2)로 해소 → 0%** (rev.1의 보수적 추정 불필요해짐) |
| 절대한도 적용 순서 | 차감 전 / 차감 후 | **1차 2건 연립으로 확정 → 차감 후(B)** (4.4절) |
| 공제방수 | 임대 가능 방 수 / 유형별 매핑 | HF 기준은 유형별 매핑. **일반 은행 일반화 근거 없음** → v1은 금액 직접 입력 |
| 방공제 법령 버전 | 2023-02-21 / 2026-07-01 | **분리 기록** — 법령 버전과 금액 기준일은 다른 값 |
| MCG 운영기관 | HF / HUG | **HF** (S10 업무처리기준으로 확정) |

### 8.3 계산 결과 표현 규칙

- 결과 라벨은 “**담보 기준 추정 한도**”. “대출 가능액”이 아닙니다.
- 필수 고지: *“LTV는 담보 기준 한도입니다. 실제 한도는 DSR·소득 인정방식·기존 부채·
  금융회사 심사에 따라 더 낮아질 수 있습니다.”*
- `unsupported` 조합은 값을 비우고 금융회사 확인을 안내합니다.
- `formatPolicyStamp()` 로 기준일·최종 확인일·출처를 결과 하단에 표기합니다.

## 10. PR 1 착수 전 남은 결정

**조사로 확정됨 — 결정 불필요**

- 절대한도 적용 범위 → 수도권·규제지역
- 생애최초 LTV → 70/80 이원화
- 수도권 비규제 유주택 → 0%

- **절대한도 적용 순서 → 차감 후(산식 B)**. 별표 18 + 금융위 문언 연립으로 확정 (4.4절)
